Daily Based MCQs Test

Posted in 10 Computer Science

These lecture notes are prepared by Salman Ahmad, who is both a teacher and a web developer. The purpose of this material is to make the topic clear and useful for students of Class 9 Computer Science.

Practice MCQs

1. What is an Operating System (OS)?
a. A web browser
b. A programming language
c. System software that manages computer hardware and applications
d. A computer game
Answer: c. System software that manages computer hardware and applications
2. Which of the following is an example of an operating system?
a. Microsoft Word
b. Linux
c. Google Chrome
d. Adobe Photoshop
Answer: b. Linux
3. What role does the operating system play in a computer?
a. Traffic controller
b. Antivirus software
c. Internet provider
d. Storage device
Answer: a. Traffic controller
4. Which task is managed by the operating system?
a. Cooking food
b. Managing memory usage
c. Printing newspapers
d. Designing buildings
Answer: b. Managing memory usage
5. The operating system acts as a ______ between the user and hardware.
a. Game
b. Translator
c. Virus
d. Cable
Answer: b. Translator
6. What happens when a user clicks an icon or types on a keyboard?
a. The monitor turns off
b. The OS converts actions into machine instructions
c. The CPU stops working
d. The printer starts automatically
Answer: b. The OS converts actions into machine instructions
7. Which of the following is NOT an operating system?
a. Android
b. macOS
c. iOS
d. MS Excel
Answer: d. MS Excel
8. Why is an operating system important in a multi-user environment?
a. It creates viruses
b. It manages users and resources fairly
c. It damages hardware
d. It removes files automatically
Answer: b. It manages users and resources fairly
9. What does the OS protect in a multi-user environment?
a. User privacy
b. Internet cables
c. Computer desk
d. Speakers only
Answer: a. User privacy
10. Which resource can be shared fairly by the operating system?
a. CPU
b. Memory
c. Printers
d. All of the above
Answer: d. All of the above
11. What does the OS use to keep users’ work secure?
a. Games
b. User accounts and passwords
c. Wallpapers
d. Speakers
Answer: b. User accounts and passwords
12. Which of the following can be different for each user account?
a. Files
b. Desktop environment
c. Settings
d. All of the above
Answer: d. All of the above
13. In a school computer lab, students log in using their own:
a. Mobile phones
b. Username and password
c. Printers
d. Speakers
Answer: b. Username and password
14. What does the operating system prevent in a shared computer system?
a. Authorized access
b. Unauthorized access
c. Typing
d. Saving files
Answer: b. Unauthorized access
15. Which operating system is mainly used on Apple mobile devices?
a. Android
b. Windows
c. iOS
d. Linux
Answer: c. iOS
