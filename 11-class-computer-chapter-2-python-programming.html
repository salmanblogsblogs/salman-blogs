What is Python Programming?

Python is a high-level, easy-to-read programming language used to create software, websites, mobile applications, games, artificial intelligence (AI), data analysis applications, and many other types of programs.

Why is Python Called Versatile?

Python is called versatile because it can be used for many different types of work. Instead of learning a different programming language for every task, you can use Python for a wide variety of applications.

What is Computer Programming?

Computer programming is the process of writing instructions (called code) that tell a computer what to do and how to do it.

A computer cannot think or make decisions on its own. It only follows the instructions given by a programmer.

It is also called coding, programming, or software in everyday language.

Setting Up Python Development Environment

Setting up a Python development environment means installing and configuring the tools needed to write and run Python programs.

Examples of Python Development Environments

These tools are commonly called Integrated Development Environments (IDEs).

  • Visual Studio Code (VS Code)
  • PyCharm
  • Google Colab (Colab)
  • Jupyter Notebook
  • IDLE
  • Spyder

1. Compiler

A compiler translates the whole program into machine code before execution. If errors are found during compilation, they must be corrected before the program can run successfully.

Examples: C and C++ commonly use compilers.

2. Interpreter

An interpreter translates and executes program code line by line. If an error occurs, it may stop execution and show an error message.

Example: Python uses interpreter.

Python Comments

What are Comments?

Comments are notes written inside a Python program to explain the code. They are ignored by the Python interpreter, so they are not executed.

Purpose of Comments

Comments are used to:

  • Explain what the code does.
  • Make the code easier to read and understand.
  • Help other programmers understand the program.
  • Remind yourself why you wrote a particular piece of code.

Types of Comments

Python mainly has two types of comments:

1. Single-Line Comment

A single-line comment starts with the # symbol.

Syntax
# This is a single-line comment
Example
# Print a welcome message
print("Welcome")

2. Multi-Line Comment

Python does not have a special multi-line comment symbol. A common way is to use triple quotes (''' or ''') to write comments that span multiple lines.

Example
"""
This program
prints a welcome
message.
"""

print("Welcome")

Rules for Naming Variables

Python has some rules for naming variables.

1. Variable names must start with a letter or an underscore (_).

✅ Correct


name = "Ali"
_age = 20

❌ Incorrect


2name = "Ali"

2. Variable names can contain letters, numbers, and underscores.

✅ Correct


student1 = "Ahmed"
total_marks = 450

❌ Incorrect


student-name = "Ahmed"

(- is not allowed.)

3. Variable names cannot contain spaces.

✅ Correct


first_name = "Ali"

❌ Incorrect


first name = "Ali"

4. Variable names are case-sensitive.

This means uppercase and lowercase letters are treated as different names.


name = "Ali"
Name = "Ahmed"

print(name)
print(Name)

Output:


Ali
Ahmed

name and Name are two different variables.

5. Do not use Python keywords as variable names.

❌ Incorrect


if = 10
class = 5

These words are reserved by Python.

Note: Reserved words (keywords) are predefined words in Python that have a special meaning. They cannot be used as variable names, function names, or class names.

A string stores text. Text is written inside single (' ') or double (" ") quotes.

4. Boolean (bool)

A boolean stores only two values:

  • False

Example

Explanation

  • True means Yes or Correct.
  • False means No or Incorrect.

Operator Precedence in Python

What is Operator Precedence?

Operator precedence is the order in which Python evaluates operators in an expression.

Simple Definition:

Operator precedence is the set of rules that determines which operation is performed first in an expression.

Operator Precedence Table

Precedence Operator Description
1 (Highest) () Parentheses
2 ** Exponent
3 *, /, //, % Multiplication, Division, Floor Division, Modulus
4 +, - Addition, Subtraction
5 ==, !=, >, <, >=, <= Comparison Operators
6 not Logical NOT
7 and Logical AND
8 (Lowest) or Logical OR

if Statement

An if statement is a control structure used to make a decision. It executes a particular block of instructions only when a given condition is true.


marks = 75

if marks >= 50:
    print("Pass")

Output:


Pass

Explanation: Since 75 >= 50 is True, the message "Pass" is displayed.

Syntax of if Statement


if condition:
    statement

if-else Statement

An if-else statement is a control structure used to make a decision between two alternatives. The if block executes when the condition is True, while the else block executes when the condition is False.

Example 1


marks = 40

if marks >= 50:
    print("Pass")
else:
    print("Fail")

Output:


Fail

Explanation: Since 40 >= 50 is False, the else block is executed and "Fail" is displayed.

Example 2


marks = 75

if marks >= 50:
    print("Pass")
else:
    print("Fail")

Output:


Pass

Explanation: Since 75 >= 50 is True, the if block is executed and "Pass" is displayed.

Syntax of if-else Statement


if condition:
    statement
else:
    statement

Shorthand If-Else in Python

In Python, the shorthand form of if-else is called a ternary operator or conditional expression. It allows us to write an if-else statement in a single line.

Syntax

value_if_true if condition else value_if_false

Example

Normal If-Else Statement:

age = 20

if age >= 18:
    print("Adult")
else:
    print("Minor")

Shorthand If-Else Statement:

age = 20

print("Adult" if age >= 18 else "Minor")

Output

Adult

Explanation

If the condition age >= 18 is True, Python prints "Adult". Otherwise, it prints "Minor".

If-Elif-Else Statement in Python

The if-elif-else statement checks multiple conditions and executes the statements in the block whose condition is true. If all conditions are false, the else block is executed.

Syntax

if condition1:
    statement1
elif condition2:
    statement2
elif condition3:
    statement3
else:
    statement4

Example

The following program checks a student's marks and displays the corresponding grade.

marks = 85

if marks >= 90:
    print("A+ Grade")
elif marks >= 80:
    print("A Grade")
elif marks >= 70:
    print("B Grade")
elif marks >= 60:
    print("C Grade")
else:
    print("Fail")

Output

A Grade

Explanation

  • if checks the first condition.
  • elif checks another condition if the previous conditions are false. We can use multiple elif blocks.
  • else executes when all the preceding conditions are false. It is optional.

Looping Construct

Definition: A looping construct is a control structure used to repeat a set of instructions again and again until a specific condition is met or for a specific number of times.

It is also called a repetitive structure or iterative structure.

While Loop

Definition: A while loop is a looping construct that repeats a set of instructions as long as a given condition is true.

Syntax


while condition:
    statement

Example


num = 1

while num <= 5:
    print(num)
    num = num + 1

Output:


1
2
3
4
5

How it works

  1. num starts at 1.
  2. The condition num <= 5 is checked.
  3. If it is true, the statement is executed.
  4. num increases by 1.
  5. The condition is checked again.
  6. When num becomes 6, the condition becomes false and the loop stops.

Python Modules and Built-in Data Structures

1. Functions and Modules

Function: A function is a block of reusable code that performs a specific task. It reduces code repetition and makes programs easier to understand.

Module: A module is a Python file that contains reusable code, such as functions, variables, and classes. We can import a module to use its features in our programs.

Example:

import math

print(math.sqrt(25))

Output:

5.0

In this example, the math module provides the sqrt() function to calculate the square root of a number.

2. Defining and Invoking a Function

Defining a function means creating a function using the def keyword. Invoking a function means calling it to execute its code.

Example:

def greet():
    print("Hello, welcome to Python!")

greet()

Output:

Hello, welcome to Python!

In this example, def greet(): defines the function, while greet() invokes the function and executes its code.

3. Function Parameters and Return Values

Parameters: Parameters are variables written inside a function's parentheses that receive values when the function is called.

Return Value: A return value is the result that a function sends back using the return statement.

Example:

def add(a, b):
    return a + b

result = add(5, 3)
print(result)

Output:

8

In this example, a and b are parameters. The function returns their sum, which is stored in the result variable.

4. Default Parameters

Default Parameters Default parameters are parameters that are assigned predefined values in the function definition. If no argument is provided for a parameter when calling the function, Python uses the default value specified in the parameter.

Example:

def greet(name="Student"):
    print("Hello,", name)

greet()
greet("Ali")

Output:

Hello, Student
Hello, Ali

In this example, "Student" is the default value of the name parameter. When greet() is called without an argument, Python uses the default value. When "Ali" is provided, the function uses that value instead.

Using Libraries and Modules in Python

1. Importing and Using Libraries

Library: A library is a collection of reusable code that helps programmers perform different tasks.

Module: A module is a Python file containing functions, variables, and classes. We can import modules to use their features without writing the code ourselves.

Example:

import math

print(math.sqrt(36))
print(math.pi)

Output:

6.0
3.141592653589793

In this example, the math module provides the sqrt() function to calculate the square root of a number and pi to represent the value of pi.

2. Importing the random Module

The random module generates random values. It is useful for games, simulations, and selecting random items.

Example:

import random

print(random.randint(1, 10))

Output (example):

7

The output may be different each time the program runs. The randint(1, 10) function generates a random integer between 1 and 10, including both numbers.

3. Importing the datetime Module

The datetime module is used to work with dates and times. It can display the current date and time.

Example:

import datetime

today = datetime.date.today()
print(today)

Output (example):

2026-10-20

The date.today() function returns the current date according to the computer's local date settings.

4. Importing the statistics Module and Using the mean() Function

The statistics module provides functions for performing statistical calculations. Its mean() function calculates the average of a group of numbers.

Example:

import statistics

marks = [70, 80, 90, 60, 100]
print(statistics.mean(marks))

Output:

80

In this example, the mean() function adds the marks and divides their total by the number of marks to calculate the average.

5. Package Structure in Python

A package is a way of organizing related Python modules into directories. It helps programmers manage large programs by grouping related code together.

In simple words, a package is like a folder that groups related Python files together.

Python Built-in Data Structures: Lists

1. Lists in Python

A list is a built-in data structure used to store multiple items in a single variable. Lists can contain different data types, such as strings, integers, floats, booleans, and even other lists. They allow duplicate values and can be modified after creation. Lists are defined using square brackets [].

1. List of Numbers

numbers = [10, 20, 30, 40, 50]
print(numbers)

Output:

[10, 20, 30, 40, 50]

2. List of Strings

fruits = ["apple", "banana", "mango"]
print(fruits)

Output:

['apple', 'banana', 'mango']

3. List of Mixed Data Types

my_list = ["Ali", 25, 5.8, True]
print(my_list)

Output:

['Ali', 25, 5.8, True]

Accessing List Items

We can access list items using their index numbers. In Python, indexing starts from 0.

Example:

fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])
print(fruits[2])

Output:

Apple
Mango

Index Number in Python Lists

An index number is the position of an item in a list. In Python, indexing starts from 0, not 1.

Example

fruits = ["apple", "banana", "mango", "orange"]

print(fruits[0])
print(fruits[1])
print(fruits[2])
print(fruits[3])

Output:

apple
banana
mango
orange

Index Positions

Item Index
"apple" 0
"banana" 1
"mango" 2
"orange" 3

Remember: The first item has index 0, the second has index 1, and so on.

You can also use negative indexing to access items from the end of a list. For example, fruits[-1] returns "orange".

Example of Negative Indexing

fruits = ["apple", "banana", "mango", "orange"]

print(fruits[-1])
print(fruits[-2])

Output:

orange
mango

Modifying a List

Modifying a list means changing the elements of an existing list, such as adding, removing, or updating items after the list has been created.

Example:

fruits = ["apple", "banana", "mango"]

fruits[1] = "orange"

print(fruits)

Output:

['apple', 'orange', 'mango']

Here, we changed "banana" to "orange" using its index number 1.

Operations on Lists

Python provides several methods to add, remove, and arrange list items.

1. append()

The append() method adds a new item to the end of a list.

Example:

fruits = ["Apple", "Banana"]

fruits.append("Mango")

print(fruits)

Output:

['Apple', 'Banana', 'Mango']

2. remove()

The remove() method removes the first occurrence of a specified value from a list.

Example:

fruits = ["Apple", "Banana", "Mango"]

fruits.remove("Banana")

print(fruits)

Output:

['Apple', 'Mango']

3. sort()

The sort() method arranges list items in ascending order by default.

Example:

numbers = [40, 10, 30, 20]

numbers.sort()

print(numbers)

Output:

[10, 20, 30, 40]

To arrange items in descending order, we can use sort(reverse=True).

Example:

numbers = [40, 10, 30, 20]

numbers.sort(reverse=True)

print(numbers)

Output:

[40, 30, 20, 10]

4. reverse()

The reverse() method reverses the current order of items in a list. It does not sort the items.

Example:

numbers = [10, 20, 30, 40]

numbers.reverse()

print(numbers)

Output:

[40, 30, 20, 10]

List Slicing

List slicing is a technique used to access a specific portion of a list. It uses the slicing syntax list[start:stop], where start is the starting index and stop is the ending index, which is not included in the result.

Syntax

list[start:stop]

Example

fruits = ["Apple", "Banana", "Mango", "Orange", "Grapes"]

print(fruits[1:4])

Output

['Banana', 'Mango', 'Orange']

Explanation: Slicing starts at index 1 and stops before index 4. Therefore, the items at indexes 1, 2, and 3 are displayed.

Negative List Slicing

Negative slicing uses negative index numbers to access a portion of a list from the end. In Python, -1 represents the last item, -2 represents the second-last item, and so on.

Syntax

list[-start:-stop]

Example

fruits = ["Apple", "Banana", "Mango", "Orange", "Grapes"]

print(fruits[-4:-1])

Output

['Banana', 'Mango', 'Orange']

Explanation: Slicing starts at index -4 and stops before index -1. Therefore, the items "Banana", "Mango", and "Orange" are displayed.

Understanding List Indexes

Item Positive Index Negative Index
Apple 0 -5
Banana 1 -4
Mango 2 -3
Orange 3 -2
Grapes 4 -1

Remember: The stop index is always excluded from the result in both positive and negative slicing.

Tuples in Python

A tuple is a built-in immutable data structure used to store multiple items in a single variable. Tuples can contain different data types, such as strings, integers, floats, booleans, and even other tuples or lists. They allow duplicate values but cannot be modified after creation. Tuples are defined using parentheses `()`. ().

Example

fruits = ("Apple", "Banana", "Mango")

print(fruits)

Output

('Apple', 'Banana', 'Mango')

1. Creating a Tuple

A tuple is created by placing items inside parentheses and separating them with commas.

numbers = (10, 20, 30, 40, 50)

print(numbers)

Output:

(10, 20, 30, 40, 50)

2. Accessing Tuple Items

We can access tuple items using their index numbers. Indexing starts from 0, which represents the first item.

fruits = ("Apple", "Banana", "Mango")

print(fruits[0])
print(fruits[2])

Output:

Apple
Mango

3. Negative Indexing in Tuples

Negative indexing allows us to access tuple items from the end. The index -1 represents the last item, while -2 represents the second-last item.

fruits = ("Apple", "Banana", "Mango", "Orange")

print(fruits[-1])
print(fruits[-2])

Output:

Orange
Mango

4. Tuple Slicing

Tuple slicing is used to access a specific portion of a tuple. It uses the syntax tuple[start:stop], where start is the starting index and stop is the ending index, which is not included in the result.

fruits = ("Apple", "Banana", "Mango", "Orange", "Grapes")

print(fruits[1:4])

Output:

('Banana', 'Mango', 'Orange')

Explanation: Slicing starts at index 1 and stops before index 4. Therefore, the items at indexes 1, 2, and 3 are displayed.

5. Tuple Operations

Python provides several operations for working with tuples. One common operation is finding the number of items in a tuple.

Finding the Length Using len()

The len() function returns the total number of items in a tuple.

numbers = (10, 20, 30, 40)

print(len(numbers))

Output:

4

Explanation: The tuple contains four items, so the len() function returns 4.

Important Points About Tuples

  • Tuples can store multiple items of different data types.

  • Tuple slicing allows us to access a portion of a tuple.
  • Tuples are immutable, which means their items cannot be changed after creation.

Advanced Python Concepts

1. Exception Handling

Exception handling is a method used to handle errors that occur while a program is running. It helps prevent a program from stopping suddenly when an error occurs.

Example: If a program tries to divide a number by zero, an error occurs. Exception handling allows us to handle this error properly and display a suitable message.

2. Try-Except Blocks

The try-except block is used to handle errors that may occur while a program is running. The try block contains code that might cause an error, while the except block handles the error if it occurs.

Example

try:
    number = 10 / 0
    print(number)
except ZeroDivisionError:
    print("Cannot divide by zero!")

Output

Cannot divide by zero!

Explanation

  • The try block contains the code that may cause an error.
  • Dividing 10 by 0 causes a ZeroDivisionError.
  • The except block handles the error and displays a message instead of allowing the error to stop the program unexpectedly.

3. File Handling

File handling is the process of creating, opening, reading, writing, and closing files using Python. It allows programs to store information permanently and access it later.

Example: A program can save students' marks in a file and read them whenever needed.

4. Opening, Reading, Writing, and Closing a File

Python provides different functions and methods to work with files. The open() function opens a file, the read() method reads its contents, the write() method writes data to a file, and the close() method closes the file.

Example: Reading a File

file = open("data.txt", "r")

content = file.read()

print(content)

file.close()

Explanation

  • open("data.txt", "r") opens the file named data.txt in read mode.
  • file.read() reads the contents of the file.
  • print(content) displays the file's contents.
  • file.close() closes the file after reading.

Example: Writing to a File

file = open("data.txt", "w")

file.write("Hello, Python!")

file.close()

Explanation

  • open("data.txt", "w") opens the file in write mode. If the file does not exist, Python creates it.
  • file.write() writes the given text into the file.
  • If the file already contains data, write mode replaces the existing content.
  • file.close() closes the file after writing.

Common File Modes in Python

Mode Purpose
"r" Opens a file for reading. The file must already exist.
"w" Opens a file for writing. Creates the file if it does not exist and replaces existing content.
"a" Opens a file for adding data at the end without replacing existing content.

Remember: The "r" mode is used to read a file, while the "w" mode is used to write data to a file. The "a" mode is used to add new data at the end of a file.

Testing and Debugging in Python

1. Testing

Testing is the process of checking a program to make sure it works correctly and produces the expected results. It helps find errors and ensures that the program meets its requirements.

Types of Testing

1. Unit Testing

Unit testing checks a small part of a program, such as a single function, to make sure it works correctly.

Example: Testing a function that adds two numbers.

2. Integration Testing

Integration testing checks whether different parts of a program work correctly together.

Example: Checking whether a login form works properly with a database.

3. Functional Testing

Functional testing checks whether a program performs its required functions according to its specifications.

Example: Checking whether a calculator correctly adds, subtracts, multiplies, and divides numbers.

4. Regression Testing

Regression testing checks whether new changes to a program have affected its existing features.

Example: After adding a multiplication feature to a calculator, testing the addition and subtraction features again to ensure they still work correctly.

2. Debugging

Debugging is the process of finding and fixing errors in a program. It helps programmers identify why a program is not working correctly and correct the problem.

Common Debugging Techniques

1. Print Statement

The print() statement is used to display variable values and program results. It helps programmers check values at different stages of a program and identify where an error occurs.

Example:

a = 10
b = 5

print("Value of a:", a)
print("Value of b:", b)

result = a + b

print("Result:", result)

Output:

Value of a: 10
Value of b: 5
Result: 15

2. Debugging Tools

Debugging tools help programmers examine a program while it runs. They allow programmers to execute code step by step, check variable values, and find errors.

Example: Python's built-in debugger, pdb, helps programmers inspect and debug their code.

3. Error Messages

Error messages provide information about problems in a program. They often show the type of error and the line where it occurred, helping programmers find and fix the problem.

Example:

print(10 / 0)

Output:

ZeroDivisionError: division by zero

Explanation: Python raises a ZeroDivisionError because a number cannot be divided by zero. The error message helps the programmer identify the problem.

Class 10 Computer Science: Python Programming FAQs

Python is a high-level, easy-to-read programming language used to create websites, software, games, AI applications, and many other programs.

Python is called versatile because it can be used for many different tasks, such as web development, artificial intelligence, machine learning, data analysis, and game development.

A comment is a note written in a program to explain the code. Python ignores comments during execution. The hash symbol (#) is used to write a single-line comment.

A variable is a named storage location used to hold data in a program. For example, age = 15 stores the value 15 in the variable named age.

Data types define the kind of data stored in a variable. Common Python data types include int for whole numbers, float for decimal numbers, str for text, and bool for True or False values.

The input() function takes data from the user, while the print() function displays information or results on the screen.

Operators are symbols or keywords used to perform operations on values and variables. Examples include arithmetic operators (+, -, *, /), comparison operators (==, !=), and logical operators (and, or, not).

An expression is a combination of values, variables, and operators that produces a result. For example, 5 + 3 is an expression that produces the result 8.

A conditional statement allows a program to make decisions based on conditions. Python uses if, elif, and else statements to execute different blocks of code depending on whether conditions are true or false.

A for loop is commonly used to repeat a block of code for each item in a sequence or over a range of values. A while loop repeats a block of code as long as its condition remains true.

A function is a reusable block of code designed to perform a specific task. The def keyword is used to define a function in Python.

A module is a Python file containing reusable code, such as functions and variables. For example, the math module provides mathematical functions, while the random module helps generate random values.

A list is a collection of items that can be changed after creation. A tuple is a collection of items that cannot be changed after creation. Lists use square brackets [], while tuples commonly use parentheses ().

Exception handling is used to manage errors that occur while a program is running. Python uses try and except blocks to handle exceptions and help prevent a program from stopping unexpectedly.

Testing checks whether a program works correctly and produces the expected results. Debugging is the process of finding and fixing errors in a program.
