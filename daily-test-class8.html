Data Communication and Computer Network

Posted in 8 Computer Science

These lecture notes are prepared by Salman Ahmad, who is both a teacher and a web developer. The purpose of this material is to make the topic clear and useful for students of Class 9 Computer Science.

Practice MCQs

1. What is WiFi used for?
a. Wired internet connection
b. Wireless internet connection
c. Satellite tracking
d. GPS navigation
Answer: b. Wireless internet connection
2. LiFi uses which medium to transmit data?
a. Radio waves
b. Sound waves
c. Light
d. Cables
Answer: c. Light
3. Cellular communication is mainly used in?
a. Television
b. Mobile phones
c. Printers
d. Cameras
Answer: b. Mobile phones
4. Satellite communication works through?
a. Underground cables
b. Space satellites
c. WiFi routers
d. Bluetooth devices
Answer: b. Space satellites
5. GPS is mainly used for?
a. Gaming
b. Navigation and location
c. Calling
d. Printing
Answer: b. Navigation and location
6. Bluetooth is used for?
a. Long-distance communication
b. Short-distance wireless connection
c. Satellite tracking
d. Internet browsing only
Answer: b. Short-distance wireless connection
7. Which technology is faster in theory than WiFi?
a. Bluetooth
b. LiFi
c. GPS
d. Cellular
Answer: b. LiFi
8. Which of the following uses radio waves?
a. LiFi
b. GPS
c. WiFi
d. Both b and c
Answer: d. Both b and c
9. Which technology does not require internet?
a. WiFi
b. Bluetooth
c. Cellular
d. Satellite
Answer: b. Bluetooth
10. GPS stands for?
a. Global Positioning System
b. General Power System
c. Global Phone Service
d. General Position Service
Answer: a. Global Positioning System
11. Which technology is used for short-range device pairing?
a. Satellite
b. Bluetooth
c. GPS
d. Cellular
Answer: b. Bluetooth
12. LiFi is based on which type of waves?
a. Radio waves
b. Light waves
c. Sound waves
d. Magnetic waves
Answer: b. Light waves
13. Which communication type requires towers?
a. Cellular communication
b. Bluetooth
c. LiFi
d. GPS
Answer: a. Cellular communication
14. Which technology helps in finding directions?
a. WiFi
b. GPS
c. Bluetooth
d. LiFi
Answer: b. GPS
15. Satellite communication is best for?
a. Short distances
b. Local networks
c. Global communication
d. Device pairing
Answer: c. Global communication
