Data Communication and Computer Network

Posted in 8 Computer Science

These lecture notes are prepared by Salman Ahmad, who is both a teacher and a web developer. The purpose of this material is to make the topic clear and useful for students of Class 9 Computer Science.

Practice MCQs

1. What does LAN stand for?
a. Large Area Network
b. Local Area Network
c. Long Area Node
d. Light Access Network
Answer: b. Local Area Network
2. A LAN is typically used within:
a. A single building
b. Multiple countries
c. Entire continents
d. Satellites
Answer: a. A single building
3. What does MAN stand for?
a. Main Area Network
b. Metropolitan Area Network
c. Medium Access Node
d. Multiple Area Network
Answer: b. Metropolitan Area Network
4. A MAN usually covers:
a. A house
b. A city
c. A country
d. The whole world
Answer: b. A city
5. What does WAN stand for?
a. Wide Area Network
b. Wireless Access Network
c. Web Area Network
d. World Access Node
Answer: a. Wide Area Network
6. The Internet is an example of:
a. LAN
b. MAN
c. WAN
d. PAN
Answer: c. WAN
7. Which network type is the fastest?
a. LAN
b. MAN
c. WAN
d. All are equal
Answer: a. LAN
8. Which network covers the largest geographical area?
a. LAN
b. MAN
c. WAN
d. PAN
Answer: c. WAN
9. A school computer lab is an example of:
a. WAN
b. MAN
c. LAN
d. Internet
Answer: c. LAN
10. Which network connects multiple LANs within a city?
a. LAN
b. MAN
c. WAN
d. PAN
Answer: b. MAN
11. Which network type is most expensive to maintain?
a. LAN
b. MAN
c. WAN
d. PAN
Answer: c. WAN
12. Which network type usually uses Ethernet cables?
a. LAN
b. MAN
c. WAN
d. Satellite Network
Answer: a. LAN
13. A network connecting branches of a bank across countries is:
a. LAN
b. MAN
c. WAN
d. PAN
Answer: c. WAN
14. Which network type has moderate speed and size?
a. LAN
b. MAN
c. WAN
d. PAN
Answer: b. MAN
15. Which of the following is NOT a type of network?
a. LAN
b. MAN
c. WAN
d. SAN (Solar Area Network)
Answer: d. SAN (Solar Area Network)
